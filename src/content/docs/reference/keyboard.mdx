On a Mac, use `Cmd` where this page says `Ctrl`, and `Option` where it says `Alt`.

## Every screen

| Keys | What they do |
|---|---|
| `Ctrl+K` | Opens or closes the command palette. See [Navigating Codex](/ui/navigation/). |
| `Up`, `Down` and `Enter` | Move through the palette and run the highlighted row. |
| `Esc` | Closes the palette. |

## Plan

| Keys | What they do |
|---|---|
| `Alt+Up` and `Alt+Down` on an act's grip | Move the act up or down. |
| `Alt+Left` and `Alt+Right` on a chapter's grip | Move the chapter within its act. |
| `Alt+Up` and `Alt+Down` on a chapter's grip | Move the chapter to the end of the previous act or the start of the next act. |
| `Alt+Up` and `Alt+Down` on a scene's grip | Move the scene up or down. Past the first or last scene of its chapter, the scene moves into the neighbouring chapter. |
| `Alt+Left` and `Alt+Right` on a scene's grip | Move the scene to the end of the previous or next chapter. |
| `Enter` in a title box | Saves the title. |
| `Esc` in a title box | Keeps the old title. |
| `Esc` while dragging | Cancels the move. |

With the View or Comment role you have no grip, so you cannot move anything. See [Plan](/ui/plan/).

## Write

| Keys | What they do |
|---|---|
| `Ctrl+B` | Makes the selected text bold. |
| `Ctrl+I` | Makes the selected text italic. |
| `Ctrl+Shift+X` | Strikes the selected text through. |
| `Ctrl+E` | Marks the selected text as code. |
| `Ctrl+/` | Switches a text field between Rich and Source. |
| `Ctrl+Alt+P` | Shows or hides the preview pane. |
| `Ctrl+Enter` | In a beat's instruction, asks for a draft. |
| `Alt+Up` and `Alt+Down` | On a beat's grip, move the beat up or down. |
| `Ctrl+click` | On an underlined name or alias, opens the Knowledge base entry. |
| `@` after a space | Opens the list of entries. `Up` and `Down` choose, and `Enter` or `Tab` inserts a mention. |
| `/` after a space | Opens the `/` menu. `Up` and `Down` choose, and `Enter` or `Tab` runs the item. |
| `Shift+Enter` or `Ctrl+Enter` | In a scene, starts a new line inside a paragraph. |
| `Esc` in focus mode | Leaves focus mode. |
| `Enter` in the replace box | Replaces the current match. |
| `Esc` on a source marker's card | Closes the card. |
| `Enter` in a table cell | Goes to the next cell. |
| `Enter` on a selected raw LaTeX chip | Opens the chip for editing. |
| `Ctrl+Z` | Undoes the last edit. |
| `Ctrl+Y` or `Ctrl+Shift+Z` | Redoes it. |
| `Ctrl+Alt+1` to `Ctrl+Alt+6` | Makes the current line a heading of that level. |
| `Ctrl+Alt+0` | Makes the current line a paragraph. |
| `Ctrl+Shift+B` | Makes the current block a block quote. |
| `Ctrl+Shift+7` and `Ctrl+Shift+8` | Start a numbered list and a bullet list. |
| `Tab` and `Shift+Tab` in a list | Indent and outdent the item. |
| `Enter` in the find box | Goes to the next match. `Shift+Enter` goes to the previous one. |
| `Esc` in the find box | Clears the search. |
| `Esc` in version history | Closes the panel. |
| `Up` and `Down` in version history | Move between saved versions. |

The Source toggle works in other Markdown fields too, such as a beat's instruction. See [Write](/ui/write/) and [Prose format](/reference/prose-format/).

## Knowledge base

| Keys | What they do |
|---|---|
| `Alt+Up` and `Alt+Down` | Move the open entry up or down among the entries in its category. |
| `Esc` | Closes the open entry. |
