Codex serves its tools, prompts and resources at `/mcp`. This page lists all of them. Its tool, prompt and resource tables come from the server's own definitions, so the names and descriptions are the ones your agent sees.

The server defines 48 tools, 4 prompts and 6 resources. Codex leaves `upload_image` out at `/mcp`, so an agent sees 47 tools. To connect an agent, see [Connect an agent](/agents/connect/). To create a token with the scopes you need, see [Tokens and scopes](/agents/tokens/).

## Scopes

Every token holds `codex:read`. A tool called without its scope fails with `forbidden`, and the message names the scope.

A call also needs a high enough role on the book it touches. A token with `codex:write` on a book shared to you for viewing fails with `forbidden`.

`undo` also needs the scope of the tool whose write it reverses. Signing off a source and accepting fair use stay in the app, whatever scopes a token has.
