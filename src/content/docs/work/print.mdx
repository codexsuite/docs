This page takes Salt and Signal from a finished draft to a PDF for the printer. Salt and Signal still has one open copyright risk, the *Signals at Sea* quote from [Clearing quotes and citing](/work/clearing/). Mara Quill clears that risk, checks the bibliography, previews the book in the template `novel-6x9` and queues the export.

You need edit access to the book and a worker that can print. Printing needs a host with Landlock ABI 4. See [Requirements](/start/requirements/). For the same route as one short guide, see [Export a print-ready PDF](/start/guides/export-pdf/). For every control on the Layout screen, see [Layout](/ui/layout/).

<Shot name="work-print-overview" alt="The Layout screen of Salt and Signal showing a page of chapter 1 in the Quick preview, with the template Novel (6 x 9)." />

## Pick a template

A template sets the page size, margins, fonts and options such as a drop cap or a table of contents. Salt and Signal uses Novel (6 × 9), the template `novel-6x9`, pinned to v1.0.0. To choose another one, open Book settings and select the Layout & print section, or use the template list on the Layout screen. In that section, Show templates lists the built-in templates and yours.

<Shot name="work-print-template" alt="The Layout & print section of Book settings, showing the template Novel (6 x 9), its version and the trim sizes." />

A book keeps the version of a template that it was first set to. When a newer version exists, the section says so and lists what changed. Select Preview to see your book with the new version, then Apply to switch. Other books stay on their version. See [Print templates](/ui/templates/).

## Page the prose while you write

To see your prose as printed pages without leaving Write, open the Format menu and set Preview to Show. A pane opens beside the prose with a Quick preview of the scene or chapter and an estimate such as `≈ 1 page`. Select Preview in Layout to continue on the Layout screen with the same template and trim.

<Shot name="work-print-write-preview" alt="Write showing scene 1.1 with the preview pane open beside the prose, set in the template Novel (6 x 9) and headed with the page estimate." />

## Check a proof of one chapter

The Quick preview is the browser's approximation. A proof is one chapter that the worker compiles with the real template. On the Layout screen, choose a chapter or a scene in the list at the left of the toolbar, then select Proof. The steps show while the worker runs. The finished pages appear under a banner that reads `Proof · chapter only, no contents or cross-references`, with Download, Log and Re-render. If the chapter changes afterwards, the banner reads `Out of date: the chapter changed after this proof`.

<Shot name="work-print-proof" alt="Layout in Proof mode showing chapter 1 as the worker compiled it, under the proof banner." />

## Read preflight

Preflight lists what will go wrong in print. On the Layout screen, select the Preflight tab. It has three groups, Blocks export, Warnings and Notes. Each row says what is wrong and links to the place that fixes it.

<Shot name="work-print-preflight" alt="The Preflight tab of Layout reading 1 issue blocks export, with the row Signals at Sea: copyright risk and the link Open in References." />

A copyright risk blocks the export. So does a missing image. An image below the resolution of the chosen Image quality, an unknown directive and raw LaTeX that the template skips are warnings.

### Error: a risk blocks the export

Select Export for printer while the risk is open. The dialog reads `1 issue blocks export`, lists the *Signals at Sea* row and disables Queue export. Codex checks the book again when you open the dialog.

<Shot name="work-print-blocked" alt="The Export for printer dialog with the line 1 issue blocks export, the Signals at Sea row and the checkbox Export a draft with DRAFT across every page." />

A request to the server for a final export gets the same answer. Codex refuses it with HTTP 422, the code `blocked` and the message `1 issue blocks export. Fix it or export a draft.` With more than one risk the message reads, for example, `3 issues block export. Fix them or export a draft.` Nothing is queued.

To go on, clear the risk or tick Export a draft. A draft export puts the word DRAFT on every page and records the blocks on the export row, so it is for reading and not for the printer.

<Shot name="work-print-draft" alt="The Exports tab with a finished export marked DRAFT." />

## Clear the last risk

Mara has permission from Tidewater Review. In References, she selects *Signals at Sea*, enters the rights holder's address, sends the letter and records the grant with the signed letter and a credit line. The steps are in [Clearing quotes and citing](/work/clearing/#ask-for-permission). The verdict changes to Needs check, the Risk chip reads 0, and the strip reads `Ready for print export`.

<Shot name="work-print-gate" alt="The References screen of Salt and Signal with the strip reading Ready for print export and no risk left." />

The other ways to clear a risk are to cut the quote or to paraphrase it. [Shorten or paraphrase](/work/clearing/#shorten-or-paraphrase) has the steps.

## Check the bibliography and the citation style

Select Bibliography on the References screen to preview the bibliography for the book. It lists the sources that a passage cites, in the style chosen in the Style list. A credit line from a granted permission shows under its source.

<Shot name="work-print-bibliography" alt="The References screen in Bibliography view, listing The Keeper's Ledger and Signals at Sea with the credit line for Signals at Sea." />

The Style list on the bibliography changes this preview only and saves nothing. The book's citation style is a setting. To change it, open Book settings, select Citations & permissions and choose a style. The styles are Chicago, APA and Harvard. Salt and Signal starts on Chicago. The example under the buttons shows how an entry reads in that style. The bibliography uses the new style the next time you open it.

<Shot name="work-print-citation-style" alt="The Citations & permissions section of Book settings with APA chosen and an example entry formatted in that style." />

<Shot name="work-print-bibliography-apa" alt="The bibliography of Salt and Signal in APA style." />

For the publisher, References can also export the permissions log as CSV and the sources as CSL JSON. Select Export on the bibliography and choose the format. The permissions log lists each source with its authors, year and credit line.

<Shot name="work-print-publisher-export" alt="The Export menu on the bibliography with BibTeX, RIS, CSL JSON and Permissions log." />

## Export for printer

1. Open Layout and select Export for printer.
2. Choose a Bleed, None, 3 mm or 0.125 in.
3. Tick Crop marks if you want them. They need a bleed.
4. Choose Image quality, Print 300 dpi or Screen 150 dpi.
5. Wait for `Ready to export`, then select Queue export.

<Shot name="work-print-ready" alt="The Export for printer dialog with a 0.125 in bleed and Print 300 dpi chosen, reading Ready to export, with an enabled Queue export button." />

The Exports tab opens. The worker picks the job up within a few seconds and the row shows the step and a percentage. When it ends, the row reads `Done` with the page count and file size.

<Shot name="work-print-exports" alt="The Exports tab with one finished export and the buttons Download, Export again with these settings and Log." />

Select Download to save the PDF. If a job shows `Failed`, the row shows the error under its settings, and Log opens the full log. A message that starts `The print sandbox could not start:` and names Landlock means the host lacks Landlock ABI 4. See [Troubleshooting](/start/troubleshooting/#an-export-or-a-proof-fails).

A queued job renders the template version it was queued with, even if you upgrade the template while the job waits.

## Ask an agent to check

An agent can run the same check. `export_for_printer` with `mode` set to `preflight` lists the blocks and queues nothing. See [Writing with an agent](/work/agents/).
