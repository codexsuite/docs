The Layout screen turns a book into pages. This guide picks a template, proofs one chapter, reads the preflight check and exports the whole book as a PDF for the printer. It uses Salt and Signal. You need a signed-in Codex, edit access to the book and a worker that can print. If a proof or export fails with a message that starts `The print sandbox could not start:`, see [Troubleshooting](/start/troubleshooting/#an-export-or-a-proof-fails).

The book has one copyright risk, the quote from *Signals at Sea*. It blocks the export until you clear it. [Clear a quote for print](/start/guides/clear-a-quote/) shows how. The steps below show the block first and then the clear export.

<Shot name="start-guides-export-pdf-overview" alt="The Layout screen of Salt and Signal, showing a page of chapter 1 in the Quick preview with the template Novel (6 x 9) and trim 6x9." />

## Pick the template and trim

1. Open Salt and Signal and select Layout.
2. Choose a template in the second list. This book uses Novel (6 × 9).
3. Choose a trim size in the list beside it.

The Template tab on the right lists the options of the template, such as a drop cap on each chapter's first paragraph and a table of contents. Each one is Off or On. The Quick preview on the left redraws as you change them. It is a fast approximation, and its status line reads `Quick · live`.

## Proof a chapter

A proof renders one chapter through the same tools as the final export.

1. Pick a chapter in the first list.
2. Select Proof.
3. Wait for `Proof finished.` The pages appear in the preview.

Download saves the proof as a PDF. Re-render makes it again. If you edit the chapter afterwards, the banner reads `Out of date: the chapter changed after this proof`. A proof has no contents or cross-references, because it is one chapter.

<Shot name="start-guides-export-pdf-proof" alt="A proof of chapter 1, The Lamp Room, with the banner Proof, chapter only, and the buttons Download, Log and Re-render." />

## Read the preflight

Preflight lists what will go wrong in print. Select the Preflight tab. Issues are in three groups, Blocks export, Warnings and notes. Each row names the problem and links to the place that fixes it, either Open in Write or Open in References.

Here one issue blocks the export: `Signals at Sea: copyright risk (permission drafted)`. Select Open in References and clear the quote. Other blocks include a missing image. Warnings include a figure below the template's target resolution, an unknown directive, raw LaTeX the template skips, and a missing Knowledge base entry or reference.

<Shot name="start-guides-export-pdf-preflight" alt="The Preflight tab reading 1 issue blocks export, with the row Signals at Sea: copyright risk (permission drafted) and a link Open in References." />

## Export for printer

1. Select Export for printer.
2. Choose a Bleed: None, 3 mm or 0.125 in.
3. Select Crop marks if you want them. They need a bleed.
4. Choose Image quality: Print 300 dpi or Screen 150 dpi.
5. Read the line under the options. Codex checks the book again when you open the dialog.

If a risk blocks the book, the line reads `1 issue blocks export` and Queue export is disabled. You have two choices. Clear the quote, or select Export a draft with DRAFT across every page. A draft export goes through with the word DRAFT on every page, so it is for reading, not for the printer.

<Shot name="start-guides-export-pdf-blocked" alt="The Export for printer dialog with the line 1 issue blocks export, the Signals at Sea row, and the checkbox Export a draft with DRAFT across every page." />

Once the risk is cleared, the line reads `Ready to export` and shows an estimated size, such as `About 1 MB`. Select Queue export.

<Shot name="start-guides-export-pdf-ready" alt="The Export for printer dialog with a 0.125 in bleed and Print 300 dpi chosen, reading Ready to export, and an enabled Queue export button." />

## Download the PDF

The Exports tab opens when the job is queued. The worker picks it up within a few seconds. The row shows the step and a percentage while it runs, and a Cancel button. When it finishes, a message reads `Print finished.` and the row reads `Done`, with the page count and the file size.

Select Download to save the PDF. Export again with these settings queues another job with the same bleed and quality. Log shows the output of the render, which helps when a job shows `Failed`.

<Shot name="start-guides-export-pdf-queued" alt="The Exports tab with one export, Done, 19 pages, 44 KB, with the buttons Download, Export again with these settings and Log." />

The job renders the template version it started with, even if the book moves to a newer version while it waits.

## Options

- Print issues, above the preview, is on by default. It shows the problem spots on the page, and clearing it hides them.
- Single and Spread switch the preview between one page and facing pages.
- Layout & print in Book settings shows when a newer version of a template is available.
- Markdown and source exports skip the print sandbox. See [Export and back up a book](/start/guides/back-up/).

See [Layout](/ui/layout/) for every control and [Getting to print](/work/print/) for the full route from draft to printer.
