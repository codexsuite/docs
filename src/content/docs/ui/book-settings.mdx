Use Book settings to change one book's title, status, style guide, citation rules, print template and sharing. You also copy, export and archive the book here. Changes save as you make them, and the top bar shows Saved or Unsaved. The screen is at `/books/<id>/settings`. To open it, select the settings icon in the book's top bar.

<Shot name="ui-book-settings-overview" alt="The Book settings screen of Salt and Signal with the Book card and the section list on the left." />

The list on the left jumps to each section: Book, Series, Writing, Citations & permissions, Layout & print, Sharing and Archive & export. The address ends in `#book`, `#series`, `#writing`, `#citations`, `#rules`, `#letters`, `#layout`, `#sharing` or `#archive`. Rules and letters are parts of Citations & permissions. `#rules` also puts the cursor in the quote limit.

## Book

Edit the Title, the Author as it prints on the cover, title page and permission letters, and the Target words. A book needs a title. Under the target, a bar shows your word count against it. Status is one of Planning, Draft, Writing, Revising or Published. Replace the cover with a PNG, JPEG or WebP image, or select Remove to go back to the generated cover.

### Publish a book

Select Published in Status. Only the owner can publish. The dialog shows the word count and how many sources are at risk. At-risk sources do not stop you from publishing, but they keep Export for printer blocked. Select Mark as published. Codex saves a snapshot of the book, a source export that appears under Snapshots in Archive & export. If the book has no chapters, the dialog says `Nothing to publish. Add a chapter first.` Published does not lock editing, and you can set another status later.

## Series

Use this section to put the book in a series, take it out or set its number. Only the owner can. See [Series](/ui/series/#add-an-existing-book-or-take-one-out). The Series screen has no setting that shares a style guide or publication settings, so set those on each book.

## Writing

The style guide is Markdown that Codex sends with every AI draft from this book, together with the beat, its context and the scene so far. Write voice, tense, point of view, spelling and words to avoid. A word count appears below it. Keep it short, because it counts against the model's context. It does not change text you already wrote.

<Shot name="ui-book-settings-writing" alt="The Writing card with a short style guide for Salt and Signal typed in." />

## Citations and rules

Choose a Citation style: Chicago, APA or Harvard. An example shows how each formats a source. Codex uses the style in the bibliography, in the citation in each source's panel and in print. Changing it updates every citation and does not change your text.

<Shot name="ui-book-settings-citations" alt="The Citations and permissions card with the citation style buttons and an example." />

Under Publisher rules, Quoted prose sets how many words from one source you may quote without permission. Codex rechecks every source in the book when you change it, and changing it back undoes it. A strip shows each quoted source against the limit and says how many sources are at copyright risk. Select Reset to restore the default. Song lyrics and poems need permission at any length, unless the licence allows reuse or the work is in the public domain. Figures, tables and images need permission unless the licence allows reuse. You cannot change those two rules.

In a book in a series, each value shows a Series chip. When you change a value, the chip reads This book. Select its × to go back to the series value.

<Shot name="ui-book-settings-rules" alt="The Quoted prose limit set to 400 words, with the strip reading No sources at risk and a Reset to 300 button." />

## Letters

Permission letters use the Publisher, Publication year, Formats, First print run and Territory and language. Fill them in before you draft a permission request. A preview, Letters will say, shows the wording with missing values highlighted. Requests you already sent keep the wording they had. See [References](/ui/references/#ask-for-permission).

<Shot name="ui-book-settings-letters" alt="The Permission letters fields and the Letters will say preview with missing values highlighted." />

## Layout

Layout & print shows the template and trim size the book uses. Change the template, trim size or a template option here or in [Layout](/ui/layout/). It also shows how many copyright risks block print export, with a link to References. Preview, proofs and Export for printer are on the Layout screen. Manage templates in [Templates](/ui/templates/).

<Shot name="ui-book-settings-layout" alt="The Layout and print card with the Novel 6 by 9 template, trim sizes, options and the print export gate." />

## Sharing

Add and remove people and set their roles here. See [Sharing a book](/ui/sharing/).

## Archive and export

### Duplicate or start a new edition

Duplicate makes a new book with this one's structure, prose, beats, Knowledge base and labels. It does not copy References, because clearance covers one book's print run. Start a new edition also copies the sources and their uses, with sign-offs and permission requests cleared. Only the owner can do either. Name the copy in the dialog. The default is `Salt and Signal (copy)` or `Salt and Signal (2nd edition)`. A link to the new book appears under the button.

### Export a manuscript

Export manuscript makes a Word, Markdown or EPUB copy for an editor or beta reader. It is not for print. Choose the format, then the scope, the full manuscript or one chapter. Include beats and Include summaries are off by default. If sources are at risk, the dialog says so and still exports. If the book has no chapters, the dialog says `Nothing to export. This book has no chapters.` One export of each format runs at a time. Select Export. A row under the button shows Queued, Running, then Done with a Download link. A failed row shows its error and a Retry button. For the full steps, see [Back up a book](/start/guides/back-up/).

<Shot name="ui-book-settings-manuscript" alt="The Export manuscript dialog with the Word format chosen and the sources at risk note." />

<Shot name="ui-book-settings-manuscript-done" alt="The Archive and export card with a Markdown export row marked Done and a Download link." />

### Back up a book

Export .zip makes a backup: Markdown with one file per scene, plus the Knowledge base, References and labels as JSON. Pending AI drafts and images are not in it. When the job finishes, the row shows `Export succeeded.`, a Download link and a note on what the backup leaves out. Import the file from Library, then Import, then Codex backup. See [Back up a book](/start/guides/back-up/).

<Shot name="ui-book-settings-backup-done" alt="The Export source row with the Export succeeded status, the Download link and the left-out note." />

### Archive a book

Archive hides the book from Library and the command palette. Codex deletes nothing, and the book keeps its number in its series. Only the owner can archive. The dialog names anyone who loses access, because archiving removes direct shares and Restore does not bring them back.

<Shot name="ui-book-settings-archive" alt="The Archive Salt and Signal dialog with the note that Ines Calloway loses access." />

After you archive, a bar reads `This book is archived: hidden from Library and the palette. Nothing was deleted.` Select Restore in the bar, or Undo in the message, to bring it back. You can also restore it from the Archived status in the [Library](/ui/library/#archived-books), where you can delete an archived book for good. To delete it, open the menu on its row, select Delete permanently, type the title and select Delete.

## When the book is shared with you

If the owner shared the book with you as Can view or Can comment, you cannot change any field. With Can view, a note at the top reads `View only. <owner> shared <book> with you to read. These are its settings as they are now; ask <owner> for edit access to change them.` With Can comment, the note starts `Comment only.` and says `to read and comment on`. With Can edit, you can change the fields, but you cannot publish the book or take it out of Published, move it, change its number, share it, duplicate it, start a new edition, archive it or restore it.
